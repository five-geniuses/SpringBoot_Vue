## 购物车模块 API 接口文档

### 1. 添加商品到购物车
- 请求路径：/api/cart/add
- 请求方法：POST
- 请求参数：
  ```json
  {
    "userId": 1,
    "goodsId": 1,
    "quantity": 1
  }
  ```
- 响应结果：
  ```json
  {
    "code": 200,
    "message": "添加成功",
    "data": true
  }
  ```

### 2. 更新购物车商品数量
- 请求路径：/api/cart/update
- 请求方法：PUT
- 请求参数：
  ```json
  {
    "cartId": 1,
    "quantity": 2
  }
  ```

### 3. 删除购物车商品
- 请求路径：/api/cart/remove/{cartId}
- 请求方法：DELETE

### 4. 获取用户购物车列表
- 请求路径：/api/cart/list/{userId}
- 请求方法：GET
- 响应结果：
  ```json
  {
    "code": 200,
    "data": [{
      "cartId": 1,
      "goodsId": 1,
      "goodsName": "string",
      "quantity": 1,
      "price": 99.99,
      "totalPrice": 99.99,
      "imgUrl": "string"
    }]
  }
  ```
